# Modulus

A keyboard, built with the idea of expansion in the future, through SPI.

Things I will do later in the future (with other Hack Club events, or with my own money):
- Numpad over SPI
- Macropad over SPI


Just use it like a keyboard! However, any SPI accessories should be connected while the keyboard is powered down. This is mainly a limitation of SPI, as it is not hot-plug compatible.
The USB ports are USB 2.0 only, so it's better to be used for stuff like USB sound cards and mice.
I don't actually know how much lag will the ports create, because they're bottom mounted, in direct contact with foam, and is air cooled. So it may overheat (tried to add thermal dissiptation vias but effectiveness not tested)

Quirks:
- Case has holes at the bottom for cooling (yes I'm serious)
